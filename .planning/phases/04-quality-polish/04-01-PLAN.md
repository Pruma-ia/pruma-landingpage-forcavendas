    2. Para cada erro TypeScript reportado, aplique a correção mínima que preserva semântica:

       PADRÃO DE ERRO ESPERADO — `iconName in iconMap` (Funcionalidades.tsx ~linha 89):
       O guard `iconName in iconMap` quando `iconName` é `string` pode não narrowar
       para `keyof typeof iconMap`. Correção:
       ```typescript
       // Antes (pode falhar strict mode):
       const Icon = iconName in iconMap ? iconMap[iconName as keyof typeof iconMap] : null;

       // Depois (narrowing explícito sem cast inseguro):
       function isIconKey(key: string): key is keyof typeof iconMap {
         return key in iconMap;
       }
       // ...então:
       const Icon = isIconKey(iconName) ? iconMap[iconName] : null;
       ```
       Coloque o type guard `isIconKey` fora da função do componente, antes de `Funcionalidades()`.

       PADRÃO DE ERRO ESPERADO — `animate()` ProvaSocial.tsx:
       Se `controls.stop` não existir na tipagem da versão instalada de framer-motion,
       substitua por:
       ```typescript
       const controls = animate(0, value, { ... });
       return () => { controls.stop?.(); };
       ```

       PADRÃO DE ERRO ESPERADO — props implícitos `any` em mockups:
       Cada função de componente sem tipo explícito no parâmetro props deve ter
       `interface XxxProps { ... }` adicionado antes da função.

       PADRÃO DE ERRO ESPERADO — imports não utilizados:
       Remova qualquer import listado como `'X' is declared but its value is never read`.
