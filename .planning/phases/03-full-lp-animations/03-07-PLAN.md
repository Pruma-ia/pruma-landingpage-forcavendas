    Line 1: `"use client";`
    Imports: `useReducedMotion` and type `Variants` from "framer-motion".
    Export an interface `FadeUpVariants { container: Variants; item: Variants; }`
    Export a function `useFadeUpVariants(staggerChildren: number = 0.08): FadeUpVariants`:
    - Calls `const reducedMotion = useReducedMotion();`
    - Declares `const item: Variants = { hidden: { opacity: 0, y: reducedMotion ? 0 : 24 }, visible: { opacity: 1, y: 0, transition: { duration: 0.4, ease: [0.16, 1, 0.3, 1] } } };`
    - Declares `const container: Variants = { hidden: {}, visible: { transition: { staggerChildren: reducedMotion ? 0 : staggerChildren } } };`
    - Returns `{ container, item }`.

    Step 2 — create `components/SectionReveal.tsx`:

    Line 1: `"use client";`
    Imports: `motion` from "framer-motion", `useFadeUpVariants` from "@/hooks/useFadeUpVariants", and React types.
    Define `interface SectionRevealProps { children: React.ReactNode; stagger?: number; className?: string; }`
    Export `function SectionReveal({ children, stagger = 0.08, className }: SectionRevealProps)`:
    - Calls `const { container } = useFadeUpVariants(stagger);`
    - Returns `<motion.div variants={container} initial="hidden" whileInView="visible" viewport={{ once: true, margin: "-60px" }} className={className}>{children}</motion.div>`

    Rules:
    - Both files use `"use client"` as line 1.
    - Hook does NOT export the `item`/`container` variants statically — they must come from the hook so reduced-motion is respected.
    - SectionReveal is a thin wrapper. It does NOT wrap each child individually — consumers wrap their own items with `<motion.div variants={item}>` (or `motion.li`, `motion.h2`, etc.) using the `item` variant returned by the same hook.
    - Easing tuple `[0.16, 1, 0.3, 1]` matches `--ease-out-expo` from globals.css.
    - Default duration 0.4s, default stagger 0.08s — matches D-06.
