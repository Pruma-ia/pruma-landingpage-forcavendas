## Trust Boundaries

| Boundary | Descrição |
|----------|-----------|
| npm registry → projeto | Dependências de terceiros instaladas via npm |
| Google Fonts CDN → browser | Fontes servidas via next/font (proxied pelo Next.js — não third-party request direto) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | npm dependencies | mitigate | Usar lock file (`package-lock.json`); verificar integridade com `npm ci` em CI |
| T-01-02 | Tampering | tailwind.config.ts tokens | accept | Arquivo de config em repositório versionado; não executa em runtime do usuário |
| T-01-03 | Information Disclosure | next/font/google | accept | next/font faz proxy interno das fontes — não expõe IP do usuário ao Google em produção; comportamento padrão documentado pela Vercel |
| T-01-04 | Denial of Service | Google Fonts fallback | mitigate | `display: "swap"` com fallbacks `system-ui` / `Georgia` / `ui-monospace` garantem que o texto seja visível mesmo se as fontes não carregarem |
| T-01-05 | Elevation of Privilege | `next.config.ts` | accept | Sem configurações de headers CSP neste plano — adicionadas na fase de qualidade (Phase 4) |
</threat_model>
